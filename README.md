# Balanzo

Balanzo is a personal finance analytics platform for tracking,
analyzing, and understanding personal spending behavior.

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- Pandas
- Streamlit
- Plotly

## Features

- [ ] Transaction management
- [ ] Expense categorization
- [ ] Spending analytics
- [ ] Data visualization
- [ ] Spending insights
- [ ] Dashboard
